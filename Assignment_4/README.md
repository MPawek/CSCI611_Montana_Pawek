# Assignment 4 - Style Transfer

## Requirements
- Python 3
- PyTorch
- torchvision
- matplotlib
- Pillow
- numpy

## How to Use
Place the image with the style to transfer in the same folder as the script, labelled style.jpg. Do the same for the image with the content to transfer, named content.jpg.
Run with the command below:
python style_transfer.py

Hyperparameters such as content_weight, style_weight, steps, learning rate, and images may be adjusted to vary output.
